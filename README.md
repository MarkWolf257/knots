# knots

knots is a web service that allows users to create their own pages of links to access online on the internet.

## Tech Stack
* Astro
* Better Auth
* Drizzle ORM
* Cloudflare

## Prerequisites
Before you begin, ensure you have the following installed:
* Node.js

## Installation
1. ### Clone the repository:
    ```bash
    git clone https://github.com/MarkWolf257/knots
   ```
2. ### Enter the directory and install dependencies:
    ```bash
    cd knots
    npm install
   ```
3. ### Environment Setup:
    Copy the '.env.example' file to '.env' and fill in the values.

## Usage
To start the development server, run:
```bash
npm run dev
```
